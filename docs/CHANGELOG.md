# Changelog

## [1.1.0] - 2025-02-01

### Added
- Multi-monitor coverage (blocks all screens)
- Process kill guard with auto-restart
- C2 status reporter with remote unlock support
- QR code placeholder generation
- Safe boot prevention option
- Attempt limiting with 60-second lockout

### Changed
- Migrated to .NET 9 with net9.0-windows TFM
- Improved countdown timer with color transitions
- Better keyboard hook stability

## [1.0.0] - 2024-10-15

### Added
- Initial release
- Fullscreen topmost lock screen
- Keyboard input blocking (low-level hook)
- Task Manager disabling
- Alt+Tab and Ctrl+Alt+Del blocking
- Countdown timer display
- Unlock code dialog
- Registry startup persistence
- JSON-based configuration
- Custom message display with wallet address
